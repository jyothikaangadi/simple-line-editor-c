# Simple Line Editor - Help

## Commands

### I - Insert Line

Inserts a new line at the specified line number.

Example:

I
Enter line number: 2
Enter text: Hello world

### D - Delete Line

Deletes the line at the specified line number.

Example:

D
Enter line number: 2

### P - Display Document

Displays all current lines with their line numbers.

Example:

P

Output:
1: Hello world
2: Welcome to the line editor

### Q - Quit

Exits the line editor.

Example:

Q
